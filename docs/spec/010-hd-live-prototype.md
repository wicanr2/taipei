# 動態 HD 比較原型

狀態：DRAFT，限 [#5](https://github.com/wicanr2/taipei/issues/5) 研究前端，不作正式 HD 完成證據。

目的：把已選 B 材質與 1280×800 接到實際原版更新，驗證施工、原版視窗、切換與清除。所有 DOS 規則、原版色號與存檔仍由 dosgolem 執行。

- 原生畫面為 320×200，前端輸出 1280×800，輸入座標除以 4 回原生座標。
- 地圖固定原生矩形 `(5,34)` 至 `(266,169)`，29×15 格，每格 9×9。來源限固定 SHA-256 的 `RS201.ROM` 成員 59，共 135 個 9×9 圖塊。
- 當前畫面須為 mode 13h、非阻塞原版輸入、頂部 270×33 的色號 SHA-256 `b9b27e2010b2d581cb55c349b5944492ea0077104e15126236fc50b859b51eda`，且 13 個材質色號的實際 RGB SHA-256 為 `9bd7a6f66fe9e1da47ea3360ffbd0e114616d466034ff8b999529ae38afe6b0b`。任一失配時整幀用原版。
- 每格仍須完整來源匹配；僅覆繪水面 144–147、沙地 201–204、樹冠 103–107。其他建設、游標、未知圖塊或缺材質保留該格原版。原型不宣稱完成建築、道路、所有動畫或字型重繪。
- 每幀先重建完整原版四倍畫面，再依當前來源覆繪；不沿用前幀遮罩。對話框、施工、切換與返回不留下舊覆繪。
- 年度預算視窗的完整可見標題另以實際色號特徵辨識，整幀回退原版；特徵與已驗相位見 [年度視窗原型](012-budget-window-prototype.md)。BIOS 非阻塞與頂部 UI 相符不能單獨證明沒有原版視窗。
- 地景材質綁定原版已完成重繪的世界座標。原點失配或尚未完成重繪時整幀回退；座標與鏡像延伸契約見 [世界座標原型](011-hd-world-origin-prototype.md)。
- 材質使用 `008-hd-material-prototype.md` 的固定 SHA-256，未知或撤除材質安全回退。原版 UI 與 F1–F6 保持原版；使用者已選定的 Noto 字型先接六個已辨識標題，固定字型、矩形與失配回退見 [Noto 動態原型](013-noto-menu-prototype.md)。其他文字仍用原版呈現。
- `-theme original|hd-b` 選原型主題；F12 即時切換，不傳入 DOS，不重開原版。使用者已確認正式版允許遊戲中切換，操作契約見 [014](014-live-theme-switch.md)；本文件其餘 HD 批次仍為 DRAFT。
- 收據保留原版 PNG、色號、色盤、機器狀態及 1280×800 呈現 PNG，使用 `capture.zip` 保存同一更新。覆繪數量及回退原因另外記錄。

預登記驗證：真實城市覆繪、原版視窗整幀回退、游標與施工格回退、材質撤除、色盤失配、來源失配、區外像素不變、切回原版逐像素相同、來源色號未改寫。完成後再走正常 GUI 冷啟動施工存退讀；快照探索只作診斷。

研究條件來源為 [hd_gate_audit.py](../../workspace/tools/hd_gate_audit.py) 與 `workspace/runs/hd-gate-audit.json`。33 份實際同幀收據及三個負對照已通過，正式接入與其他 HD 批次仍依 #6、#7、#8 的閘門。
