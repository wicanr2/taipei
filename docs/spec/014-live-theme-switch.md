# 遊戲中原版／HD 切換

狀態：**READY**。對應 [#6](https://github.com/wicanr2/taipei/issues/6)，正式接入與玩家驗收分別由 [#7](https://github.com/wicanr2/taipei/issues/7)、[#8](https://github.com/wicanr2/taipei/issues/8) 完成。入口：[CONTEXT.md](../../CONTEXT.md)。本契約只定義切換，不代替完整 HD 素材規格。

## 使用者定案

使用者於 2026-10-11 回覆「允許在遊戲中切換」，選定前題提出的 F12 即時切換。B 細緻手繪材質、1280×800、Noto 高清黑體與三平台沿用既有定案。

## 輸入、狀態與輸出

| 項目 | 契約 |
|---|---|
| 輸入 | 視窗取得鍵盤焦點時，F12 每次新按下切換一次；持續按住不反覆切換 |
| 前端狀態 | 原版與 HD 兩態互換，下一次呈現更新生效 |
| DOS 輸入 | F12 的按下與放開都不送入 DOS；原版 F1–F10 沿原路由 |
| 原版機器 | 沿用同一機器與目前遊戲，不重開、載入快照、重設亂數或改寫遊戲資料 |
| 原版畫面 | 切回原版時，由當前原版色號及色盤完整產生四倍畫面，清除 HD 地景與文字 |
| HD 畫面 | 從當前原版畫面重新辨識來源；視窗、失配來源、缺素材等回退規則仍生效 |
| 模擬與存檔 | 切換不自動暫停、不額外推進原版時間、不寫存檔；原版正常運行與存讀檔照常 |
| 未定範圍 | 完整 HD 重繪批次另依 #6，不由本操作契約推定 |

## 證據審查

原版輸入、工具及圖形條件沿用 [Noto 原型](013-noto-menu-prototype.md) 與[持續運行研究](../re/007-running-city.md)。固定 EXE SHA-256 為 `798db7f69e287690814f4e7b588be733fc0ad28a6ad943eb397d1f82528db3b3`。本項為新前端操作，沒有對應的原版 F12 語意或反組譯位址。

- 已證實：研究前端 [Update](../../workspace/app/cmd/taipei-preview/main.go) 使用新按下事件，只切換 `hdEnabled` 與前端收據；DOS 按鍵表不含 F12。
- 已證實：`workspace/runs/gui-cold/` 的 `pause`、`theme-original`、`theme-hd` 三份原子收據依序為 HD、原版、HD。三份原版色號 SHA-256 都是 `a838e6e26f6af4f62a2fc9a6c945e2671c2b5fa8194d80f01b028791a20fe000`，六筆 DOS 讀鍵紀錄逐項相同。虛擬步數自然前進，沒有重開或載入快照。
- 已證實：三份地景覆繪數依序為 433、0、433，Noto 標題數為 6、0、6。固定參考與回退像素核對見 `gui-cold/font-verification.json` 及 013；後續施工存退讀通過，存檔雜湊不變。
- 已證實：呈現層在固定正常輸入、相同初始狀態與虛擬步數下不改變原版機器狀態，收據 `workspace/runs/noto-state-audit.json`。範圍與兩側 2,400,000,000 步的比較項目見 013；不外推全遊戲 parity。

## 正式接入驗收

既有證據足以建立操作契約；目前程式仍為研究前端，不以此宣稱 CONFORMED。

- 正式前端從真實入口新遊戲，F12 往返、施工、存檔、原版退出與全新啟動讀檔。保留原版／呈現兩側收據及來源雜湊。
- 在暫停的相同城市核對切換前後原版畫面及 DOS 讀鍵不變，切回原版完整清除，返回 HD 依當前來源恢復。
- 在原版視窗及缺素材時切換，仍依呈現回退規則；按住 F12 不連續切換。這兩項尚未有正式 GUI 驗收證據。
- 實際三平台封包的快捷鍵及系統功能鍵限制，依 #9 分別記錄結構、Wine 與真機驗證，未驗不宣稱通過。

只涉及前端呈現及輸入攔截，沒有新增遊戲資料格式、原版存檔欄位或可散布的原版資產。原版與衍生畫面留在本機，正式包的權利邊界沿用 AGENTS.md。
