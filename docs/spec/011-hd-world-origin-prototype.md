# HD 地景世界座標比較原型

狀態：**DRAFT**。對應 [#24](https://github.com/wicanr2/taipei/issues/24)。本契約只修正 [動態比較原型](010-hd-live-prototype.md)，不進正式產品路徑。正式 HD 仍待 #6 的字型、操作與素材批次定案。

## 證據與界線

原版原點讀寫、圖塊資料索引及重繪尾聲見 [地圖原點證據](../re/006-map-origin.md)。遊戲專用位址留在本專案 `internal/original`。HD 繪圖器只接收已分型的圖塊原點，不讀取或修改 dosgolem。

## 原型契約

- EXE 必須符合既有 SHA-256。原點段指標必須符合已查證的 MZ 重定位結果。
- 原點使用圖塊座標，水平範圍 0 至 76、垂直範圍 0 至 74。原型不推算地圖或游標位置。
- 只在原版 `0744:280D` 到達重繪尾聲時記錄原點。首次重繪完成前，以及讀到的原點與最近完成原點不同時，顯示原版。
- 原版 UI、色盤、完整來源圖塊、素材雜湊與未知來源回退條件繼續生效。
- HD 像素使用 `worldX=originX*36+screenX-20`、`worldY=originY*36+screenY-136`。同一個世界位置與原版色號必須得到相同材質像素。
- 沿用 1254×1254 的本機 B 材質。超出素材邊界採鏡像延伸，週期為 2508，邊界相鄰像素取同一邊緣像素。這是原型呈現方法，未宣稱素材已獲正式美術驗收。
- 來源與色盤不變時，材質定位只改輸出 RGBA。原版記憶體、CPU、色號緩衝、亂數與存檔保持原樣。

## 預先登記的核對

| 核對 | 通過條件 |
|---|---|
| 原點與原版幾何 | #23 的充分辨識位移，其 `dx,dy` 等於收據原點差 |
| 世界材質相位 | 每組位移中，相同原版圖塊且合格的世界格，實際 36×36 HD 像素逐一相同 |
| 原點負對照 | 無完成事件、錯誤段指標、超界值或未完成捲動都回退原版 |
| 邊界延伸 | 素材邊緣兩側及鏡像週期切點沒有越界，相鄰邊緣像素取樣相同 |
| 遮擋與恢復 | 選單、取消、兩次主題切換及未知圖塊維持既有逐像素回退條件 |
| 原版狀態 | 相同冷啟動、固定步數與鍵盤輸入下，有／無觀察與繪圖的 RAM、CPU、原版畫面、色盤及亂數條件相同 |

驗證結果追加於研究文件及 WORKLOG；DRAFT 原型通過不把本規格標成正式 CONFORMED。
