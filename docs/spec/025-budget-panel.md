## 動態欄位

下表座標全部相對面板左上。空白位補色號 3，ASCII 墨色只接受 0 或 12，字距 6。完整重建 31,020 個像素，不遮罩動態區。

清除十一欄後的固定背景 SHA-256 為 `28ed84d785657fa26eb5118196c147aa29b1eb97c3b1184829e1ebea6fb1d654`。ROM2 由第四 byte 後依非零 literal 或 `0,color,count` 解碼，count 是原 byte 數值；輸入及輸出均完整消耗、尺寸及雜湊符合才採用。這只證實本成員，不將混合 ROM 所有成員視為同一 codec。

|---|---|---|---|
| 五列百分比 | 93 | 29／49／68／85／103 | 各 3 |
| 四列費用 | 168 | 49／68／85／103 | 各 8 |
| 稅收 | 51 | 120 | 8 |
| 淨額 | 168 | 120 | 8 |

正式辨識要求：每欄為右對齊十進位文字，只容許空白、數字與單一前置負號；五個百分比恰有一列為選取色 12，其餘為 0，四費用、稅收及淨額皆為 0。ASCII 原字模、完整背景及全部動態像素重建相同才接受。保留原字串及空白，不由整數重新格式化，不假定稅率上下限或重寫任何數值規則。

呈現器輸入僅為 64,000 色號、256×3 色盤、mode 及主題旗標。辨識結果保存十一個原字串、十一個墨色與選取列。以三欄／八欄長度檢查固定原位，再用 Noto 數字字距 24 像素繪製，白／紅兩種墨色對應原版 0／12。每幀完整覆蓋面板，面板外保留原版四倍像素。原版或未知來源的收據不填 HD 欄位。

完整來源須在既有年度預算回退及阻塞判斷前辨識；不同視窗維持各自完整來源。預算素材失配只影響本面板，不讓部分數字或底板疊入原版，也不影響其他已完成家族。完整來源、使用中色盤、固定素材任一失配均返回整幀原版，不計為完成。

## 原版操作與生命週期

- 已證實正常 F3 預算選項及年度入口使用相同背景與欄位模型。
- 已證實 Up／Down 五列循環，Right 減一、Left 增一；HD 不交換方向。Space 保留視窗，Escape 返回。閒置由原版時間與計數處理，HD 不加入逾時或關窗。
- 初批各項調整已先還原才 Escape；不能由初批推論撤銷。後續 `budget-native-ranges/result.json` 已證實 Escape 保留調整、Enter 保留視窗：10／100 調成 9／99 後 Escape 再開仍為 9／99，存檔後再改成 8／99，正常 F2 重讀後回到 9／99。實際 SAV 不被讀檔改寫；這是同一 EXE 的正常重讀，尚未當作全新 EXE 驗收。
- 每幀從原版重建欄位，重新合成完整高清底板；不保留上一幀文字或選取。返回、切換與重讀由正常 GUI 驗證，不以狀態注入代替。

實作後另驗完整來源、固定高清參考、全部區外、字形墨跡、單項資源故障與兄弟家族隔離。有效負對照須重算 PNG 與雜湊；正常五列／數值變化／F12／返回／重開、施工存退讀與兩次原版退出通過。實作前在 #39 登記唯一正常輸入、完整步數與每 24,000,000 步抽樣，要求預算實際覆繪且原版狀態及實際 SAV 相同。
