# B 風格地形材質原型

狀態：DRAFT。日期：2026-10-11。對應 [#16](https://github.com/wicanr2/taipei/issues/16)。
入口：[CONTEXT.md](../../CONTEXT.md)。本規格只允許離線、可撤回的比較原型。

- 使用同一份 dosgolem 原版畫面與 320×200 原始色號，輸出 1280×800。
- 讀取已驗證 ROM 容器及 9×9 圖庫，完整 81 bytes 精確匹配後才覆繪。
- 初批限成員 59 中已目視盤點的水面、沙地、樹冠色號。其他內容保持原版四倍縮放。
- 材質由內建 imagegen 生成，提示詞、輸入、輸出雜湊留本機；不入 Git。
- 只改地圖矩形內、來源完整匹配的像素。未知來源、游標與遮擋破壞匹配時回退原版。
- 材質使用整張地圖的連續座標取樣，避免每格重起造成接縫。不新增海岸線、建築或遊戲狀態。
- 輸出原版四倍、覆繪圖及覆蓋／回退計數，確認區域外像素相同。
- 這不證明繪圖事件來源、動畫、捲動或正式主題切換。仍須以實際動態畫面建立正式 READY 契約。

初批不改 UI、文字與快捷鍵。字型選擇待可並列原型，未定案內容不進正式前端。
