## 可撤回的美術與幾何原型

原型候選為成員 39 的 15–29、43–55、60–74，共 43 張。這是供來源及視覺審查的候選，尚未證明包含全部道路、跨水面、疊加與交通相位。其他索引保持未知，不因圖庫相鄰就歸入同一功能。

- 瀝青採內建 imagegen 新繪的細緻手繪材質，沒有道路方向、線條、物件或文字；提示詞保存在 `asphalt-b-v1.prompt.txt`。原圖 1586×992，SHA-256 `7b172889bb71eb4a8bb65393e8caaae790afd1eed69529a71a612cffd20b85ae`；轉為 1254×1254 的材質 SHA-256 `61057d15840d65801652de6af95b1b27b56706d67774a66f41bec3fb852cd384`。
- 地景沿用已確認的水面、沙地及樹冠材質。新道路表面、標線與電線筆觸重新組合；不將原圖直接四倍放大當作重繪。
- 每個高清像素取原版格上相鄰四點的色號與雙線性權重，合併相同色號後，以最大餘數法量化為總和 255 的四組 byte。原點位於原像素中心，邊界夾限；每個原像素在四倍格內的中心分類必須保留。
- 原型資料為每格 1296×4 個色號 byte 與同數量的權重 byte。地景及瀝青使用世界座標的鏡像延伸索引；其他色號依原色明暗繪製新筆觸。這只是呈現資料，不成為原版道路連接或模擬規則。
- v2 色彩採千分比整數材質明暗、最近偶數捨入的筆觸及總和 255 的整數混合。原 v1 保留，避免浮點跨實作邊界影響可重現結果。二十四張世界材質測圖涵蓋正／負座標及鏡像交界，僅是離線座標契約，不能代替正常 GUI 捲動。
- v3 將相鄰兩點的線性比例 `t` 改為 `t²(3−2t)`，縮窄標線與電線的混色帶。獨立核對器以分母 262144 的整數面積重算，不引用產生器。每個原像素的四個中央高清像素都須保留原分類；v1／v2 不覆寫。
- 原位比較發現 v3 的瀝青顆粒在 36×36 道路上過大。v4 將同一固定瀝青材質及其筆觸取樣改為世界座標乘四，再鏡像延伸；其他地景與原版幾何保持。此修訂只調新材質的尺度，v3 保留作前件。
- [#45](https://github.com/wicanr2/taipei/issues/45) 的 v4 乾淨重建發現 PNG 時間戳造成 byte 差異，解碼像素相同。v5 改為固定標準庫 RGBA8 PNG，只含 IHDR／IDAT／IEND、filter 0 與 zlib level 9，記錄 zlib 編譯及執行版本；幾何、素材與像素保持 v4。
- `infrastructure_prototype.py` 只寫候選素材、完整來源雜湊、原位比較及 manifest，不由產品載入。新插畫、圖層形狀及材質相位須先視覺及獨立核對。

本節仍為 DRAFT，來源範圍及相位補齊後才固定表格與雜湊。內部呈現資產格式不改原版 ROM、EXE、施工規則或 SAV。

- 正式狀態輸入產生後、重播前，在 Issue 登記唯一收據 SHA-256、步數、工具及兩側初始條件。兩側相同輸入與虛擬時間，抽樣原版狀態與實際 SAV；抽樣須真正畫到本家族。
