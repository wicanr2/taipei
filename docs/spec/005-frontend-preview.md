# 原版 GUI 研究原型

狀態：DRAFT。日期：2026-10-11。對應 [#4](https://github.com/wicanr2/taipei/issues/4)。
入口：[CONTEXT.md](../../CONTEXT.md)。本規格只准可撤回研究原型，不是正式產品路徑。

- 直接 import 固定 dosgolem 基底及本專案補丁。載入已驗證 EXE 與 `/A /D /x`。
- 原版資料唯讀；DOS.Scratch 指向獨立存檔目錄。原版格式交由 EXE 讀寫。
- 使用 Ebiten 2.9.9 顯示原版 320×200 與 DAC 色盤，暫用四倍整數視窗。
  這是研究視窗，不代表 HD 解析度或平台定案。
- 鍵盤按下／放開送 set 1 通斷碼，不同時寫 Stdin。滑鼠座標除以顯示倍率，
  經現有 DOS 驅動介面送入，不自造點擊熱區。
- 每次更新執行固定指令數。輸入、畫面、原版規則、存檔仍由原版執行。
- 研究收據包含原版畫面、CPU／鍵盤／檔案紀錄。可載入診斷快照，但不能用其取代冷啟動驗收。
- 本階段暫無音訊輸出。既有 `/x` 入口的音訊與正式速度仍待查證。
- 原型不得宣稱核心操作、存退讀或跨平台完成。取得實際 GUI 證據後再補正式 READY 契約。
